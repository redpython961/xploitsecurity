Why XFSA

Firewalls drift. Attackers notice first.

Rules pile up, temporary access becomes permanent, firmware falls behind and management interfaces end up on the internet. XFSA turns a configuration export into a clear, prioritized and defensible picture of your firewall's security posture.

Full-configuration coverage

Every rule, object and system setting is evaluated, not a sample. Sections the parser can't read are reported as Not Assessed, never as compliant.

Vulnerability & misconfiguration detection

Firmware is matched to vendor advisories with CVSS scores and fixed releases; risky rules and weak settings are flagged automatically.

Compliance scoring

Pass, fail, manual-review and N/A results per control, with compliance percentages for each selected standard.

Evidence for every finding

Each finding quotes the exact configuration lines that triggered it, with the expected secure configuration.

Remediation you can apply

Plain-language remediation plus vendor CLI snippets, technical risk and business impact (confidentiality, integrity, availability).

Deterministic and repeatable

Findings come from version-controlled rules, not AI guesses, so results are consistent, explainable and audit-friendly.

What it checks

Eight security domains, one rule library.

The Xploit Firewall Security Baseline groups checks into the domains attackers and auditors care about.

Authentication & administration

Default and excess admin accounts, MFA, password and lockout policy, trusted hosts, banners, LDAP over TLS.

Network security & firewall policies

Any-any rules, insecure services, untrusted inbound access, disabled or undocumented rules, unlogged denies.

VPN & cryptography

Weak IPsec ciphers, integrity algorithms and DH groups, IKEv1, legacy TLS on SSL VPN, VPN without MFA.

Monitoring & logging

Remote log forwarding, logging on rules, authenticated NTP, SNMP v1/v2c and default communities.

Security inspection

IPS, anti-malware, web filtering, application control and DNS security on internet-bound and published traffic.

Infrastructure & resilience

Exposed management planes, HA, routing protocol authentication and vendor-specific hardening settings.

Vulnerabilities

Running firmware checked against known CVEs with affected ranges, CVSS scores and fixed releases.

Compliance mapping

Every rule mapped to NIST SP 800-53, PCI DSS 4.0.1, the Xploit baseline and vendor hardening controls.

Reporting

Risk your leadership understands in one page.

Every report opens with an overall risk score, a security score, compliance percentage, findings by severity and domain, the key weaknesses and prioritized recommendations, ready for a CISO, auditor or board pack.

  • Risk score from 0 to 10 and security score out of 100
  • Findings by severity: Critical, High, Medium, Low, Informational
  • Top weaknesses with individual risk scores
  • Priority recommendations in order of impact
  • Detailed findings with evidence, CLI remediation, CVE and mapped controls

How it works

From configuration file to board-ready report.

01

Export

Export the firewall configuration and register the device, its criticality and environment.

02

Parse

XFSA parses the configuration, records its SHA-256 hash and shows which sections it could read.

03

Assess

Version-controlled rules evaluate the configuration against the standards you select.

04

Report & fix

Download the report, remediate with the provided steps and re-assess to confirm the fixes.

Methodology

Transparent scoring you can defend.

Risk scores combine each rule's base severity with exposure (reachability from untrusted zones), device criticality and environment. CVSS is used as a floor for known vulnerabilities.

No AI-generated findings

No AI service generates findings or evidence. Every result traces back to a specific rule and configuration line.

Honest coverage

Controls that can't be determined from configuration are marked Manual Review; missing sections are Not Assessed.

Traceable input

The analyzed file is identified by its SHA-256 hash, so every report is tied to an exact configuration.
